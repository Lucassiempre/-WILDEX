# Imágenes

El prototipo usa fotografías remotas desde Wikimedia Commons mediante `Special:FilePath`.

No se redistribuyen fotografías dentro del repositorio para evitar incluir recursos sin revisar sus condiciones específicas de reutilización. Cada ficha enlaza a la página de Wikimedia Commons correspondiente para consultar autoría y licencia.

El ícono oficial está en `public/images/wildex-icon.png` y se usa en el encabezado y el favicon. El logo completo se conserva en `public/images/wildex-logo.png` para una futura pantalla de presentación. Ambos fueron suministrados como recursos de identidad de WILDEX y no deben reutilizarse fuera del proyecto sin autorización del titular.
